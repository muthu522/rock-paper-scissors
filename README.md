Rock Paper Scissors Game 🎮

This is a simple Rock–Paper–Scissors web game created using HTML, CSS, and JavaScript.
The player plays against the computer, and the result is displayed after each round.

Technologies Used

  * HTML
  * CSS
  * JavaScript
  
Project Files

   Rock.html – Main HTML file
   Rock.css – Styling of the game
   Rock.js – JavaScript game logic
   README.md – Project description

Features

   Player vs Computer gameplay
   Random choice generation for the computer
   Displays win, lose, or tie result
   Keeps track of player and computer scores
   Simple and clean user interface
   
How to Run the Game

   Download or clone the repository
   Open the project folder
   Open Rock.html in any web browser

How the Game Works

   The player selects Rock, Paper, or Scissors by clicking a button
   The computer randomly selects one option
   JavaScript compares both choices
   The result and scores are updated on the screen
